- موقع مطور

## الـ Flow الكامل

### 1. Intro Loader *(مهم جدًا)*

أول ما الموقع يفتح:

- شاشة سودا تقريبًا
- صوت subtle جدًا *(اختياري)*
- **hand-writing animation** — cursor بيكتب:

```
Ahmed Najiebe
Building systems beyond interfaces.
```

بعدها:
- smear transition
- blur dissolve
- يدخل على الـ Hero

---

### 2. Hero Section

مش مجرد text.

**الخلفية:**
- animated particles
- flowing gradients
- grid perspective
- slow moving light

**النص — Huge Typography:**

```
I build
immersive digital systems
for real-world impact.
```

**Animation — كل سطر بطريقة مختلفة:**
- واحد → slide
- واحد → blur reveal
- واحد → handwritten underline

---

### 3. التنقل بين السكاشن *(الـ Magic)*

كل ما تنزل section جديد:

1. تظهر **overlay صغيرة full-width**
2. اسم الـ section يتكتب بـ hand-writing animation:
   ```
   Selected Work
   ```
3. الـ overlay تختفي
4. الـ section يطلع **cinematic**

زي transitions بتاعة الأفلام — وده اللي هيخليك مختلف.

---

### 4. Projects Section

مش cards عادية.

كل project:
- huge preview
- mouse parallax
- hover → cinematic zoom
- animated glow trails
- scrolling reveals

لما تفتح project → **immersive case study** كاملة.

---

### 5. "Command Center Mode" *(الفكرة السرية)*

في الـ background — خصوصًا بسبب **Polluscan**:

- live fake system data
- floating metrics
- environmental graphs
- sensor particles

ده هيخليك مختلف جدًا عن أي portfolio تاني.

## الأخطاء الـ 3 القاتلة — احذر منها

### ❌ 1. Too Many Animations
الناس هتتعب. لازم يبقى فيه **لحظات هادية**.

### ❌ 2. Slow Performance
لو FPS وقع → كله ضاع.  
Performance = respect للـ user.

### ❌ 3. No Hierarchy
كل حاجة مهمة = مفيش حاجة مهمة.  
لازم يبقى فيه **visual breathing room**.

---

## القاعدة الذهبية

> **Every animation feels intentional.**

مش effects مرمية.  
مش animations كتير بلا معنى.  
مش lag.  
مش dopamine overload.

كل حركة ليها **سبب**.
