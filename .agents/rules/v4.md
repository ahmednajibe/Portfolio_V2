# Portfolio Redesign — Project Instructions

## Project Name
Ahmed Najiebe — Cinematic Interactive Portfolio

---

# Project Goal

Build a highly immersive futuristic portfolio experience that combines:
- cinematic storytelling
- premium UI/UX
- smooth animations
- interactive motion
- futuristic system-inspired visuals
- emotional transitions

The website should feel like:
- an interactive digital experience
- a sci-fi product presentation
- a modern cinematic portfolio

NOT a traditional developer portfolio.

---

# Main Design Direction

## Style Keywords
- cinematic
- futuristic
- premium
- immersive
- atmospheric
- interactive
- emotional
- elegant
- modern

---

# Visual Inspiration

Inspired by:
- Linear
- Stripe
- Apple
- Raycast
- Awwwards websites
- Sci-fi interfaces
- Interactive product launches

---

# Core Philosophy

Every section should feel like entering a new scene or chapter.

Motion should guide emotion.

Animations must feel intentional and cinematic.

The portfolio should feel alive.

---

# Technical Requirements

## Framework
Use:
- Vue.js
or
- Nuxt

## Styling
Use:
- TailwindCSS

## Animation Libraries
Required:
- GSAP
- Lenis

Optional:
- Three.js
- OGL
- Motion One
- Splitting.js

---

# Performance Rules

Animations must remain smooth.

Target:
- 60 FPS
- optimized rendering
- lightweight transitions
- minimal lag

Avoid:
- unnecessary heavy effects
- excessive particles
- too many simultaneous animations

---

# General UI Rules

## Design Language
- dark futuristic theme
- soft gradients
- subtle glow
- matte surfaces
- premium typography
- clean spacing

## Avoid
- cyberpunk overload
- excessive neon
- too much glassmorphism
- cluttered layouts

---

# Typography

## Primary Font
Use:
- Satoshi
or
- General Sans

## Accent Font
Use handwritten font ONLY for:
- section titles
- transition overlays
- annotations

Recommended:
- Caveat
- Kalam

# 1. Intro Loader

## Goal

Create a powerful first impression.

## Requirements

- black background
- grain texture
- blinking cursor
- handwriting animation

Text example:

```
Ahmed Najiebe
Building systems beyond interfaces.
```

## Transition

After loading:

- blur dissolve
- cinematic fade
- smooth hero reveal

---

# 2. Hero Section

## Layout

Full-screen immersive hero.

## Background

Include:

- animated particles
- moving gradients
- atmospheric glow
- perspective grid
- subtle noise texture

## Main Heading

Huge cinematic typography.

Example:

```
I build immersive digital systems
for real-world impact.
```

## Animations

Use:

- stagger reveal
- blur transitions
- text masks
- handwritten underline effect

---

# 3. Section Transition System

## Important Feature

Whenever user enters a new section:

Show cinematic overlay with handwritten animated text.

Example:

```
Selected Work
```

## Behavior

- text writes live
- overlay fades out
- next section reveals smoothly

Transitions should feel cinematic.

---

# 4. Selected Work Section

## Goal

Projects should feel immersive.

NOT static cards.

## Features

- parallax movement
- hover zoom
- animated lighting
- mouse-follow effects
- cinematic reveal animations

## Layout

Large project showcases.

Focus on:

- visuals
- storytelling
- interaction
- architecture
- impact
